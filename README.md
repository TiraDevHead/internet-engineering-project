# پروژه مهندسی اینترنت

سامانه ثبت‌نام و جست‌وجوی اطلاعات کاربران با **PHP و SQLite**. رابط کاربری فارسی و راست‌به‌چپ است و برای یک پروژه درسی طراحی شده است.

## امکانات

- ثبت اطلاعات **نام، نام خانوادگی، شماره موبایل، کد ملی و ایمیل**
- اعتبارسنجی سمت سرور، شامل بررسی رقم کنترل کد ملی ایران
- کپچای تصویری سمت سرور با امکان دریافت کد جدید
- جلوگیری از ثبت کد ملی یا ایمیل تکراری
- نمایش پیام موفقیت و خطا پس از ارسال فرم
- ورود مدیر و جست‌وجوی کاربران از طریق کد ملی
- نمایش مشخصات ثبت‌شده فقط به مدیر واردشده
- طراحی واکنش‌گرا با تم آبی و سفید

## فناوری‌ها

| بخش | فناوری |
| --- | --- |
| بک‌اند | PHP 8.1+ |
| پایگاه داده | SQLite با PDO |
| فرانت‌اند | HTML، CSS و JavaScript |
| احراز هویت مدیر | Session و `password_hash` / `password_verify` |

پروژه برای اجرا به Composer یا npm نیاز ندارد.

## پیش‌نیازها

- PHP نسخه **8.1** یا جدیدتر
- افزونه **`pdo_sqlite`** در PHP
- دسترسی نوشتن به پوشه `data/`

وضعیت PHP و افزونه‌ها را با دستورهای زیر بررسی کنید:

```powershell
php -v
php -m
```

نام `pdo_sqlite` باید در خروجی دستور دوم وجود داشته باشد. در صورت غیرفعال بودن، افزونه را در فایل `php.ini` فعال کنید. برای پیدا کردن این فایل می‌توانید از `php --ini` استفاده کنید.

## راه‌اندازی در ویندوز

**۱.** مخزن را دریافت کنید (با Git یا دانلود ZIP)، سپس در PowerShell به پوشه پروژه بروید. برای نمونه:

```powershell
cd D:\Projects\internet-engineering-project
```

**۲.** اولین مدیر را بسازید:

```powershell
php bin/create_admin.php
```

نام کاربری پیش‌فرض `admin` است (با زدن Enter) و رمز عبور باید حداقل ۱۲ کاراکتر باشد. پیام‌های این اسکریپت انگلیسی‌اند تا در ترمینال ویندوز درست نمایش داده شوند. **رمز عبور ممکن است هنگام تایپ قابل مشاهده باشد**؛ آن را در محیط خصوصی وارد کنید.

**۳.** سرور توسعه PHP را اجرا کنید:

```powershell
php -S 127.0.0.1:8000 -t public public/router.php
```

به‌جای دستور بالا می‌توانید فایل `start-windows.bat` را اجرا کنید.

**۴.** صفحات سایت را باز کنید:

| صفحه | آدرس محلی |
| --- | --- |
| ثبت‌نام | http://127.0.0.1:8000/ |
| ورود مدیر | http://127.0.0.1:8000/login.php |
| جست‌وجوی کاربران | http://127.0.0.1:8000/search.php |

صفحه جست‌وجو نیاز به ورود مدیر دارد.

## راه‌اندازی در Linux / macOS

از پوشه اصلی پروژه:

```bash
php bin/create_admin.php
sh start-mac-linux.sh
```

در برخی سیستم‌های لینوکسی لازم است افزونه SQLite متناسب با نسخه PHP جداگانه نصب شود.

## پایگاه داده

پس از اولین دسترسی موفق به دیتابیس، فایل `data/app.sqlite` به‌صورت خودکار ایجاد می‌شود و جدول‌های `users` و `admins` ساخته می‌شوند. تعریف جدول‌ها به‌صورت جداگانه در `database/schema.sql` نیز موجود است.

**فایل دیتابیس و اطلاعات واقعی کاربران نباید وارد مخزن Git شوند.** مسیر دیتابیس در `.gitignore` مستثنا شده است. اگر از قبل دیتابیسی روی سیستم دارید، پیش از جایگزین کردن فایل‌ها از آن نسخه پشتیبان تهیه کنید و پوشه `data/` را تغییر ندهید.

## ساختار فایل‌ها

```text
internet-engineering-project/
├── bin/
│   └── create_admin.php       # ساخت یا تغییر رمز حساب مدیر
├── data/
│   └── .gitignore             # دیتابیس در زمان اجرا ساخته می‌شود
├── database/
│   └── schema.sql             # ساختار جدول‌ها
├── public/
│   ├── assets/                # CSS، JavaScript و favicon
│   ├── index.php              # صفحه ثبت‌نام
│   ├── register.php           # پردازش و ذخیره فرم
│   ├── captcha.php            # تولید کپچا
│   ├── refresh-captcha.php    # دریافت کد جدید
│   ├── login.php              # ورود مدیر
│   ├── logout.php             # خروج مدیر
│   ├── search.php             # جست‌وجوی کاربران
│   └── router.php             # مسیریابی سرور توسعه
├── src/                       # توابع، تنظیمات و قالب مشترک صفحات
├── tests/
│   └── smoke.php              # آزمون‌های پایه
├── start-windows.bat
├── start-mac-linux.sh
└── README.md
```

## اجرای تست‌ها

```powershell
php tests/smoke.php
```

برای بررسی نحوی فایل‌های PHP در PowerShell:

```powershell
Get-ChildItem -Recurse -Filter *.php | ForEach-Object { php -l $_.FullName }
```

## نکات امنیتی

- جست‌وجو و نمایش اطلاعات کامل کاربران فقط پس از ورود مدیر امکان‌پذیر است.
- پروژه از توکن CSRF، کوئری پارامتری، هش رمز عبور و خروجی HTML ایمن‌سازی‌شده استفاده می‌کند.
- محدودیت تعداد تلاش‌ها در سطح Session اعمال شده و جایگزین محدودسازی مناسب برای محیط عمومی نیست.
- سرور `php -S` صرفاً برای توسعه محلی است. برای انتشار عمومی، **DocumentRoot** باید روی پوشه `public/` تنظیم شود و فایل دیتابیس خارج از دسترس وب بماند.
- پیش از جمع‌آوری اطلاعات واقعی افراد در اینترنت، HTTPS، کنترل دسترسی، پشتیبان‌گیری امن و الزامات حریم خصوصی را بررسی کنید.
