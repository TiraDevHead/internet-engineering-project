# آبی‌فرم | سامانه ثبت‌نام و جست‌وجوی کاربران

یک وب‌سایت کامل، فارسی، راست‌به‌چپ، واکنش‌گرا و **بدون نیاز به نصب پکیج‌های Composer یا npm**.

## امکانات

- فرم ثبت‌نام شامل نام، نام خانوادگی، موبایل، کد ملی ایرانی و ایمیل
- کپچای **تصویری و سمت سرور**، با قابلیت دریافت کد جدید و انقضای ۱۰ دقیقه‌ای
- اعتبارسنجی کامل سمت سرور (از جمله رقم کنترل کد ملی ایران)
- پشتیبانی از ارقام فارسی/عربی و نرمال‌سازی شماره‌های موبایل `09…` و `+98…`
- جلوگیری از ثبت تکراری کد ملی یا ایمیل در سطح دیتابیس
- پیام موفقیت / خطا همراه با نگه‌داشتن مقادیر فرم در صورت خطا
- ورود مدیر با رمز عبور هش‌شده و صفحه جست‌وجوی کاربر از طریق کد ملی
- نمایش نام، نام خانوادگی، موبایل، کد ملی، ایمیل و تاریخ ثبت‌نام به مدیر
- طراحی مدرن آبی-سفید همراه انیمیشن ملایم، مناسب موبایل و دسکتاپ

## پیش‌نیازها

- **PHP 8.1 یا جدیدتر** (پیشنهاد: PHP 8.2/8.3/8.4)
- افزونه‌های PHP: `PDO`، **`pdo_sqlite`** و `sqlite3` (برای PDO فقط `pdo_sqlite` ضروری است)
- دسترسی نوشتن PHP به پوشه `data/`
- هیچ سرور دیتابیس مستقلی لازم نیست؛ SQLite یک فایل دیتابیس دارد. نسخه خالی آن نیز همراه پروژه ارسال شده است.

بررسی پیش‌نیاز:

```bash
php -v
php -m
```

باید نام `pdo_sqlite` را در خروجی `php -m` ببینید. اگر نبود، در `php.ini` مربوط به نسخه CLI یا وب، افزونه `extension=pdo_sqlite` را فعال کنید؛ در XAMPP/Windows ممکن است نام آن `extension=php_pdo_sqlite.dll` باشد. پس از تغییرات سرور را مجدداً راه‌اندازی کنید.

## راه‌اندازی با ویندوز

۱. پوشه پروژه را از فایل ZIP خارج کنید.

۲. در Command Prompt / PowerShell وارد پوشه‌ای شوید که فایل `README.md` داخل آن است:

```powershell
cd C:\path\to\blue-register
```

۳. **ابتدا حساب مدیر بسازید:**

```powershell
php bin/create_admin.php
```

نام کاربری (پیش‌فرض `admin`) و یک رمز عبور حداقل ۱۲ کاراکتری را در ترمینال تعیین کنید. هیچ نام کاربری و رمز عبور پیش‌فرض/هاردکدشده‌ای وجود ندارد.

۴. سایت را اجرا کنید:

```powershell
php -S 127.0.0.1:8000 -t public public/router.php
```

یا در صورت در دسترس بودن دستور `php`، روی فایل `start-windows.bat` دوبار کلیک کنید.

۵. صفحات را در مرورگر باز کنید:

- ثبت‌نام: <http://127.0.0.1:8000/>
- ورود مدیر: <http://127.0.0.1:8000/login.php>
- جست‌وجو (پس از ورود): <http://127.0.0.1:8000/search.php>

> اگر ویندوز می‌گوید `php is not recognized`، مسیر پوشه PHP یا XAMPP (مثلاً `C:\xampp\php`) را به `PATH` اضافه کنید، یا دستورها را با مسیر کامل `C:\xampp\php\php.exe` اجرا کنید.

## اجرا در macOS / Linux

```bash
cd blue-register
php bin/create_admin.php
./start-mac-linux.sh
```

روی برخی توزیع‌های لینوکس افزونه SQLite بسته‌ای مجزاست؛ نام بسته معمولاً `php-sqlite3` است. نصب باید با نسخه PHP مطابقت داشته باشد.

## نصب روی هاست / Apache

**DocumentRoot را فقط روی پوشه `public/` تنظیم کنید**، نه ریشه پروژه. فایل دیتابیس، اسکریپت‌های مدیر و کدهای `src` نباید از طریق وب منتشر شوند.

- PHP دارای `pdo_sqlite` باشد.
- پوشه `data/` قابل نوشتن ولی از دسترسی عمومی وب خارج باشد.
- فعال‌سازی HTTPS و تنظیم درست Session Cookie ضروری است.
- یک بار از خط فرمان، `php bin/create_admin.php` را اجرا کنید.
- در Apache لازم نیست rewrite فعال باشد، همه مسیرها فایل PHP مستقیم‌اند.
- سرور داخلی `php -S` فقط برای **توسعه محلی** است و مناسب انتشار عمومی نیست.

## نحوه استفاده

۱. کاربر فرم را پر و کپچا را وارد می‌کند. پس از موفقیت، نوتیفیکیشن سبز می‌بیند. هر ثبت‌نام در جدول `users` ذخیره می‌شود.

۲. مدیر از بخش «ورود مدیر» وارد می‌شود و به «جست‌وجوی کاربران» می‌رود. با وارد کردن کد ملی معتبر، اطلاعات کامل کاربر نمایش داده می‌شود.

۳. داده‌ها در `data/app.sqlite` ذخیره می‌شوند. فایل خالی آن همراه پروژه قرار دارد و اگر حذف شود، پس از اولین اتصال دیتابیس به‌طور خودکار ساخته خواهد شد. نسخه پشتیبان باید همراه فایل‌های `-wal` و `-shm` یا با API رسمی بکاپ SQLite تهیه شود؛ فقط کپی فایل اصلی هنگام فعالیت سامانه، ممکن است کافی نباشد.

### راه‌اندازی سریع مدیر پس از تغییر رمز

همان دستور `php bin/create_admin.php` را تکرار کنید و **همان نام کاربری** را وارد کنید. رمز حساب موجود به‌روزرسانی می‌شود.

## ساختار پروژه

```text
blue-register/
├── public/                    # تنها پوشه‌ای که باید در دسترس وب باشد
│   ├── index.php              # صفحه ثبت‌نام
│   ├── register.php           # ذخیره ثبت‌نام
│   ├── captcha.php            # کپچای SVG
│   ├── refresh-captcha.php    # ایجاد کپچای جدید
│   ├── login.php              # ورود مدیر
│   ├── logout.php             # خروج امن
│   ├── search.php             # جست‌وجوی محافظت‌شده
│   ├── router.php             # برای سرور توسعه PHP
│   └── assets/                # CSS, JS, favicon
├── src/                       # بوت‌استرپ، توابع، سربرگ، پابرگ
├── bin/create_admin.php       # ایجاد/تغییر رمز حساب مدیر
├── database/schema.sql       # تعریف جدول‌های دیتابیس
├── tests/smoke.php            # تست توابع اصلی
├── data/app.sqlite            # دیتابیس خالی SQLite (خارج از دسترس عمومی)
├── start-windows.bat
└── start-mac-linux.sh
```

## نکات امنیتی و حریم خصوصی

این پروژه برای نمونه اجرایی/پروژه‌های کوچک طراحی شده و موارد زیر را دارد: CSRF Token، Queryهای پارامتری، رمز عبور هش‌شده، کپچای سمت سرور، محدودسازی ساده تلاش‌ها در Session، محافظت از پنل مدیر، خروج با POST، پاک‌سازی HTML هنگام نمایش داده‌ها و کوکی‌های HttpOnly/SameSite.

**برای استفاده عمومی و دریافت اطلاعات واقعی افراد باید پیش از انتشار:**

- سیاست حریم خصوصی، مبنای قانونی جمع‌آوری کد ملی، اطلاع‌رسانی و رضایت مناسب کاربران مشخص شود.
- HTTPS، بکاپ رمزگذاری‌شده و محدودسازی دسترسی سرور/فایل‌ها فعال گردد.
- نرخ‌دهی مبتنی بر IP/حساب، لاگ دسترسی‌های مدیریتی، مانیتورینگ و کنترل‌های ضدربات قوی‌تری (مانند Turnstile/reCAPTCHA با کلیدهای واقعی) درنظر گرفته شود. محدودسازی فعلی فقط برای هر Session است.
- بهتر است مدیریت نقش‌ها، سیاست نگه‌داری/حذف داده و رمزگذاری داده‌های حساس در حالت سکون (at rest) اضافه شود؛ SQLite معمولی به‌صورت پیش‌فرض رمزگذاری ندارد.
- حساب‌های مدیر دارای رمز عبور یکتا و قوی باشند. این پروژه سیستم ایمیل تأیید و بازیابی رمز عبور ندارد.

> **توجه:** کد ملی، تلفن و ایمیل اطلاعات شخصی‌اند؛ به همین دلیل صفحه جست‌وجو عمومی نیست و نیاز به ورود مدیر دارد.

## تست‌ها

```bash
php tests/smoke.php
find public src bin -name '*.php' -exec php -l {} \;
```

کد پروژه مستقل از کتابخانه‌های ثالث است. برای امتحان ثبت‌نام واقعی، وجود PDO SQLite الزامی است.
